# FitLens (formerly NutriLens AI) — Legal pages

Static GitHub Pages site for the FitLens Android app (`com.nutrilens.calorie.tracker.ai`).

| Page | URL |
|---|---|
| Index | https://mokshgiri.github.io/nutrilens-ai/ |
| Privacy Policy | https://mokshgiri.github.io/nutrilens-ai/privacy-policy.html |
| Terms & Conditions | https://mokshgiri.github.io/nutrilens-ai/terms-conditions.html |

The app reads these URLs from Firebase Realtime Database (`/showConfigs/privacyPolicyUrl`,
`/showConfigs/termsUrl`), and the Privacy Policy URL is also set in Play Console. The URLs were kept when the
app was renamed to FitLens so nothing else needed to change.

Edit the HTML, commit and push to `main`; GitHub Pages republishes within a minute or two.
